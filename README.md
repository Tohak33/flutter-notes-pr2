# Заметки на Flutter

Практическая работа № 2. **Куприков Антон, группа П-2-24.**

Приложение выполняет требования на оценку 5:

- ввод текста и добавление заметки кнопкой «Сохранить»;
- отображение заметок списком под полем ввода;
- удаление выбранной заметки;
- редактирование существующей заметки через то же поле ввода;
- отмена редактирования и проверка пустого текста.

Заметки хранятся в `List<String>` в памяти. После полного перезапуска приложения список очищается. Постоянное хранение в задании не требуется.

## Запуск

Нужен установленный Flutter SDK (проект проверен с Flutter 3.38.7 / Dart 3.10.7).

```sh
flutter pub get
flutter run
```

Перед запуском выберите подключённый Android-телефон или эмулятор. Для браузера:

```sh
flutter run -d chrome
```

## Проверка и сборка

```sh
flutter analyze
flutter test
flutter build apk --debug
```

## Как пользоваться

1. Введите текст и нажмите «Сохранить». Заметка появится ниже, поле очистится.
2. Нажмите значок карандаша у заметки. Её текст появится в поле, а запись будет выделена рамкой.
3. Измените текст и нажмите «Сохранить»: запись обновится без добавления копии.
4. Для выхода из режима редактирования нажмите «Отмена».
5. Значок корзины удаляет соответствующую запись.
